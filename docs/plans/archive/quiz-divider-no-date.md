# クイズのセッション区切りから日付を外す

## 目的・背景

クイズを始めるとチャット欄のセッション区切りに「7/30 クイズ」と日付が表示されるが、
クイズの区切りは固定文言「クイズ」だけでよく、日付は不要（ユーザー要望）。
会話・単語モードの区切り（「7/30 トピック名」「7/30 単語: X」）は従来どおり日付を残す。

## 対応方針

- `ChatRoomStore` に区切り全文を組み立てる純関数 `dividerText(mode:title:date:)` を追加する
  （会話・単語は「日付 ラベル」、クイズはラベル = 固定文言「クイズ」のみ）
- 区切りを作る 2 箇所（`startSession` の開始時と `restoreTimeline` の復元時）を
  この関数に寄せる。復元も同じ関数を通すことで、再起動後にクイズの区切りへ
  日付が復活しない（表示の一貫性）
- `dividerLabel` / `dividerDateText` はそのまま（組み立てだけを新関数に集約）

## 影響範囲

- 変更: `ChatRoomStore.swift`（`dividerText` 追加・`startSession` / `restoreTimeline` の 2 呼び出し）
- 保存データ: 変更なし（区切りは表示時に組み立てており永続化していない）

## テスト方針

- 単体テスト（`PracticeModeCardTests`）: `dividerText` がクイズだけ日付を省き、
  会話・単語は「M/d ラベル」形式になること
- `xcodebuild` でビルド + 全テストパス
- シミュレータ: 再起動して復元された過去のクイズ区切りが「クイズ」（日付なし）、
  単語・会話の区切りは日付付きのままであることをスクリーンショットで確認
  （開始時と復元は同じ関数を通るため、開始時の表示は単体テストで担保）
