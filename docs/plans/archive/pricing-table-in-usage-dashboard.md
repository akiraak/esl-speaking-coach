# AI モデルの単価表を管理画面「料金」タブに表示する

2026-07-31 作成。

## 目的・背景

管理画面「料金」タブ（`UsageDashboardView`）は推定額のサマリ・種別内訳・日別一覧を表示しているが、
**計算の根拠になっている単価表**はアプリ内のどこにも表示されていない（`Usage/AIPricing.swift` と
`docs/specs/ai-cost-map.md` にしかない）。推定額を見たときに「いまどの単価で計算しているか」を
アプリ内で確認できるようにする。sonnet-5 の導入価格（〜2026-08-31）→通常価格の切替も表示に反映されると、
9 月以降に金額が上がった理由がその場で分かる。

## 対応方針

1. **`AIPricing` に表示用の単価表を追加する**（単一情報源を保つため、View に文字列をベタ書きしない）
   - `RateRow`（モデル名 / 用途 / 単価文字列 / 補足）と `rateTable(at:) -> [RateRow]` を追加
   - 単価の数値は計算で使っている定数・`claudeRates(model:at:)` から組み立てる。計算式に埋まっている
     リテラル（live $0.017/分、4o フォールバック $0.006/分、Gemini $1/$20・25 トークン/秒、
     mini-tts $0.015/分 など）は名前付き定数へ抽出し、計算と表示の両方から参照する
   - sonnet-5 は `at` の日付で導入価格 / 通常価格を切り替え、導入価格期間中は補足に切替日と改定後単価を出す
2. **`UsageDashboardView` に「単価表」セクションを追加する**
   - 日別一覧の下に配置。行はモデル名 + 用途 + 単価 + 補足の簡素な表示
   - footer に「推定額は記録時の単価で保存するため、改定後は過去の記録とこの表が一致しない」旨を明記
3. **`docs/specs/ai-cost-map.md` に追記**: 単価改定時の注意（AIPricing とこの文書を併せて更新）に、
   管理画面の単価表は `AIPricing` から生成されるため自動で追従する旨を 1 行足す

## 影響範囲

- `EslSpeakingCoach/Usage/AIPricing.swift`（表示用 API の追加・定数抽出。計算結果は変えない）
- `EslSpeakingCoach/Admin/UsageDashboardView.swift`（セクション追加）
- `EslSpeakingCoachTests/AIPricingTests.swift`（テスト追加）
- `docs/specs/ai-cost-map.md`（1 行追記）
- 新規ファイルなし（XcodeGen 再生成は不要）

## テスト方針

- 既存の `AIPricingTests` が全て通ること（定数抽出で計算結果が変わっていないことの確認）
- `rateTable(at:)` のテストを追加: 導入価格期間中の sonnet-5 行は $2/$10 + 補足あり、
  終了後は $3/$15 + 補足なしに変わること
- シミュレータビルドが通ること。表示はシミュレータの管理画面「料金」タブで目視確認
