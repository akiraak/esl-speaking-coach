# セッション終了ボタンを分かりやすい場所に置く

## 目的・背景

セッション終了（「トピックを終える」）はヘッダの ⋯ メニューの中に隠れており、
会話を切り上げたいときに 2 タップ + メニューを開くまで存在に気づけない。
セッション終了はフィードバック生成につながる主要導線なので、ヘッダに常設の
ボタンとして出す。

## 対応方針

- `ChatRoomView` のヘッダに「終了」ボタン（`flag.checkered` + ラベル）をピル型で常設表示する
  - アクセント色（`ChatTheme.accent`）で目立たせる
  - セッション中（`store.isSessionActive`）のみ表示。非セッション時は出さない
- ⋯ メニューからは「トピックを終える」を削除する（メニューは管理画面のみ残る）
- 露出が上がって誤タップしやすくなるため、`confirmationDialog` で確認を挟む
  （終了は opus のフィードバック生成を走らせるので取り消しが効かない）

## 影響範囲

- `EslSpeakingCoach/Conversation/ChatRoomView.swift`（ヘッダのみ）
- 仕様書 `docs/specs/screen-layout.md` のヘッダ記述を同期

## テスト方針

- 既存ユニットテストが通ること（UI 変更のみでロジックは触らない）
- シミュレータでセッション開始 → ヘッダの終了ボタン表示 → 確認 → フィードバック生成、
  非セッション時にボタンが出ないことを確認
