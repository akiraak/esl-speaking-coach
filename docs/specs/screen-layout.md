## トーク画面

```
┌────────────────────────────┐
│ ESL Group (3)           ⚙ │ ← ヘッダ: ルーム名 + メンバー数 + 設定
├────────────────────────────┤
│ ── 7/25 Travel plans ──    │ ← セッション区切り
│ (Mia) [Mia]                │
│  Where would you go?       │ ← AI: 左寄せ・アバター + 名前
│              I'd go to Peru│ ← ユーザー: 右寄せ・アクセント色
│ ┌────────────────────────┐ │
│ │ 📝 Session Feedback     │ │ ← フィードバックカード
│ └────────────────────────┘ │
│ ┌────────────────────────┐ │
│ │ 📌 次のトピック          │ │ ← トピックカード
│ │ ▷ Planning a trip       │ │
│ │ ▷ Food you can't quit   │ │
│ │ ▷ Free talk             │ │
│ │ [🔄 他の候補] [＋自分で] │ │
│ └────────────────────────┘ │
├────────────────────────────┤
│ [🎤] [Aa メッセージ…] [↑]  │ ← 入力バー（テキストモード時）
└────────────────────────────┘
```

### ヘッダ

- ルーム名（固定。例: "ESL Group"）+ メンバー数
- 右端に設定ボタン（⚙）→ 設定画面をシート表示
- セッション終了操作「トピックを終える」はヘッダのメニュー（⋯ または ⚙ と並置）に置く

### タイムライン

表示要素は次の 5 種類。すべて同一のスクロールタイムラインに時系列で積む。

1. **AI メッセージ**: 左寄せ。アバター + 名前ラベル付き（LINE のグループトーク準拠）。2 キャラはそれぞれ固有のアバター・名前を持つ
2. **ユーザーメッセージ**: 右寄せ・アクセントカラーの吹き出し。自分のアバター・名前は表示しない（LINE 準拠）
3. **トピックカード**: 後述
4. **フィードバックカード**: セッション終了時に投稿される（内容・詳細レイアウトは「セッション後のフィードバック生成」タスクで定義）
5. **システムメッセージ**: エラー・再接続・セッション区切り（日付 + トピック名）。中央寄せのグレー小文字テキスト

表示挙動:

- 新規メッセージ追加時は最下部へ自動スクロール（ユーザーが手動で遡っている間は自動スクロールしない）
- **ライブ文字起こし**: 発話中の partial transcript は右寄せ・半透明の吹き出しで表示し、確定後に通常のユーザーメッセージへ置き換える
- **応答生成中**: LINE 風の「〜が入力中…」インジケータをタイムライン最下部に表示
- **読み上げ中**: 発話中キャラのアバター横にスピーカーアイコン（🔊）を表示
- 検証用の RMS 数値・レイテンシ表示・エンジン切替 UI は製品画面には出さない（必要なら DEBUG ビルドのみ）

### トピックカード

- **投稿タイミング**: 初回起動時、およびセッション終了（フィードバックカード投稿）直後に自動で投稿する
- **内容**: Claude が事前生成したトピック候補 3 件 + 「Free talk」
- **操作**:
  - 候補をタップ → そのトピックでセッション開始
  - 「🔄 他の候補」→ 候補 3 件を再生成して同カードを差し替え
  - 「＋ 自分で作る」→ 1 行のテキスト入力（シートまたはアラート）を開き、入力したトピックでセッション開始
- 選択済み・過去のカードはグレーアウトして履歴に残す（タップ無効）

### 入力バー

LINE 同様の入力バーを基本形とし、マイクボタンで音声モードへ「変形」する。

```
テキストモード:
│ [🎤] [Aa メッセージを入力…] [↑] │
        ↓ 🎤 タップ / ⌨ タップで復帰
音声モード（ハンズフリー連続）:
│ [⌨] ● 〰〰〰〰〰〰〰〰 [⏸]     │
```

- **テキストモード**: テキストフィールド + 送信ボタン。左端のマイクボタンで音声モードへ
- **音声モード**: ハンズフリー連続。サーバ VAD（無音 800ms）でターン検出、読み上げ中の barge-in 可。聞き取り中は波形（マイクレベル連動）をアニメーション表示。⏸ で聞き取り一時停止 / 再開、左端のキーボードボタンでテキストモードへ
- モードはセッション・アプリ再起動をまたいで保持する
- どちらのモードでも会話履歴・AI 応答・読み上げの挙動は同一（テキスト送信でも AI は音声で返す）

### 状態とバーの対応

| 会話状態 | 入力バー（音声モード） | タイムライン |
| --- | --- | --- |
| 聞き取り中 | 波形アニメーション | （発話中は半透明のライブ吹き出し） |
| 応答待ち | 波形停止・薄色 | 「〜が入力中…」 |
| 読み上げ中 | 波形停止（barge-in は受付） | 発話キャラに 🔊 |
| エラー / 切断 | 再接続ボタン表示 | システムメッセージ |

## セッションの流れ

1. トピックカードで候補を選ぶ or 自作トピックを入力 → セッション開始（区切りのシステムメッセージを投稿）
2. 音声またはテキストで会話する
3. ヘッダメニューの「トピックを終える」→ フィードバック生成（別タスク）→ フィードバックカード投稿
4. 直後に次のトピックカードが自動投稿される（→ 1 に戻る）

- アプリを閉じた場合、進行中セッションは次回起動時にそのまま継続表示する

## キャラクター

- AI 2 キャラは名前・アバター・人格・TTS voice をアプリ内定義の固定値で持つ（設定画面での編集は将来検討）
- アバターは当面イニシャル or SF Symbols ベースのプレースホルダで良い（画像アセットは任意）
- 具体的な名前・人格・voice の割り当ては実装フェーズで決める

## ビジュアルデザイン（案 D「ポップ・スタディ」）

4 案比較（LINE クラシック / iOS ミニマル / ダークフォーカス / ポップ・スタディ）から選定。モックアップは `docs/specs/screen-design-mockups.html`（案 D を採用）。

**トーン**: 語学アプリ寄りの明るい暖色。大きめの角丸とカラフルなアバターで 2 キャラの「相手感」を最大化し、続けたくなる楽しさを重視する。

### カラーパレット（ライト）

| 要素 | 値 |
| --- | --- |
| チャット背景 | `#FDF3E3`（暖色クリーム） |
| ヘッダ / 入力バー背景 | `#FFFFFF` |
| AI 吹き出し | 背景 `#FFFFFF` / 文字 `#45351F` |
| ユーザー吹き出し | 背景 `#F0642F`（コーラルオレンジ） / 文字 `#FFF6EF` |
| ライブ文字起こし吹き出し | `#F0642F` の 20% 透過 / 文字 `#B5502A` / 斜体 |
| アクセント（波形・送信ボタン・カードタイトル・🔊 表示） | `#F0642F` |
| トピック / フィードバックカード | 白地、枠 `rgba(120,80,40,0.12)` |
| トピック候補ピル | 通常 `#FBEEDD` / 選択済み `#FFE1D2` + 文字 `#CF4A17` |
| システムメッセージ | 文字 `#96775C` / 背景 `rgba(120,80,40,0.10)` のピル |
| 名前ラベル | `#A08464` |
| アバター | Mia `#EF5DA8` / Leo `#3D9BE9`。白フチ 2px + 薄い影 |

### 形状・タイポグラフィ

- 角丸: 吹き出し 20pt（しっぽ側の角のみ 6pt）、カード 20pt、トピック候補はピル型（full）
- 吹き出し・カードに `rgba(120,80,40,0.1)` 程度のごく薄い影
- フォントはシステムフォント。ヘッダタイトルは太め（heavy / bold）、本文 medium
- 入力バー: テキストフィールドは `#F7ECDC` のピル型、送信ボタンはアクセント色の円形

### ダークモード

暖色トーンを保ったままの再設計が必要（単純反転はしない）。配色は実装フェーズで決める（未決事項）。

## 受け入れ条件（実装タスクの確認項目)

- [ ] 起動すると（キー設定済みなら）直接トーク画面が開く
- [ ] AI 2 キャラのメッセージがアバター + 名前付きで左寄せ、ユーザーが右寄せで表示される
- [ ] トピックカードから候補選択・再生成・自作入力の 3 操作ができ、選択でセッションが始まる
- [ ] マイクボタン⇔キーボードボタンで音声 / テキストモードが往復でき、モードが再起動後も保持される
- [ ] 音声モードで、聞き取り中の波形・partial transcript・「入力中…」・読み上げ中 🔊 が状態どおり表示される
- [ ] テキスト送信でも音声と同じ会話フロー（AI 応答 + 読み上げ）になる
- [ ] 「トピックを終える」でセッションが終了し、区切り表示と次のトピックカードが投稿される（フィードバックカードは該当タスク完了後）

## 未決事項（実装フェーズで決める）

- **AI 2 キャラのターン進行方式**（「会話画面の UI」実装時に決定）。候補:
  - 台本方式: ユーザー発話ごとに Claude を 1 回呼び、両キャラ分（0〜2 発話）を speaker タグ付きで受け取る。レイテンシ・コスト最小。文単位 TTS（`SentenceChunker`）に speaker 属性を通す実装が必要
  - キャラ別呼び出し: キャラごとに別 system prompt。人格独立性は高いがコスト・レイテンシ約 2 倍
  - メイン + 相槌固定: 1 キャラ主導 + もう 1 キャラは短い相槌のみ
- キャラの名前・人格・TTS voice の具体値
- ダークモードの配色（案 D の暖色トーンを保った再設計。単純反転はしない）
- フィードバックカードの詳細レイアウト（「セッション後のフィードバック生成」タスクで定義）
