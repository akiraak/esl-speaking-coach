トーク画面 デザイン案 — 4 方向の比較

レイアウトは仕様書（docs/specs/screen-layout.md）どおり 4 案とも共通です。表示している要素も同一 — 選択済みトピックカード / セッション区切り / AI 2 キャラ（Mia・Leo）の吹き出し / ユーザー吹き出し / 発話中のライブ文字起こし / 音声モードの入力バー — で、配色とトーンだけを変えています。

案 A LINE クラシック

LINE の既視感をそのまま再現する案。青グレー背景 + 白吹き出し + 緑のユーザー吹き出し。

  • 迷わない: 毎日使う LINE と同じ操作感覚で会話に集中できる
  • 名前ラベルは背景上に白文字（LINE グループ準拠）
  • ダークモード時は背景を紺系に落とす想定
案 B iOS ミニマル

iMessage 系の純正トーン。白背景 + グレー/ブルー吹き出しで、標準アプリのように静か。

  • 実装が最も素直: システム色ベースでライト/ダーク対応がほぼ自動
  • 装飾が少ないぶん英文テキストの可読性が最も高い
  • 個性は薄め。キャラ感はアバター色だけで出す
案 C ダークフォーカス

ダーク常用前提の集中モード。ティールのアクセントで「録音中」の状態を主役にする。

  • 夜の練習・長時間セッション向き。波形と状態表示が最も映える
  • ダークが基本形。ライトモードは補助として用意
  • SNS 感より「トレーニングツール」感が強い
案 D ポップ・スタディ

語学アプリ寄りの明るいトーン。暖色地 + 大きめの角丸で、キャラの存在感を最大化。

  • 続けたくなる楽しさ重視。2 キャラの「相手感」が最も強い
  • トピック候補はピル型で押しやすさを演出
  • 好みが分かれる方向。ダーク対応は配色の再設計が必要

選び方

1 案そのまま採用でも、「案 B のベースに案 C のダークを重ねる」「案 A の配色でカードだけ案 D 風」のような組み合わせ・調整指示でも OK です。決定後、選定内容を仕様書に「ビジュアルデザイン」節として追記します。
